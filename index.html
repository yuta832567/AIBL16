Security & Concerns
運用にあたっての基本方針（セキュリティ）
※ 以下は池田様から挙がった懸念点ではなく、経理データなど機密情報を扱う前提で、AIBLからお伝えする基本方針です。初級編でも改めてご説明します。
🛡️ 大前提： 生成AIはとても便利な一方で、使い方を誤ると情報漏洩につながることがあります。特に経理では決算・仕入先・金額といった大切な情報を扱うため、安全な使い方を最初に押さえてから進めるのが、結果的に安心かつ最短ルートになります。

🫥 機密情報はマスキングして扱う

決算資料・仕入先情報・取引金額など、見られたくない情報はマスキング／ダミーデータに置き換えてから渡すのが基本です。社外秘・取引先の非公開情報はそのまま入力しないようにします。

🔢 金額など「間違えてはいけない数字」は人が最終確認

AIは考える作業が得意な一方、金額の入力・転記そのものを丸ごと任せるのには向きません。仕分けの下ごしらえ・整理をAIに任せ、最終確認は必ず人が行うのが安全な使い方です。

🔐 データの学習設定に注意

ChatGPTには、やり取りを学習に使う設定があります。無料版でも設定で切り替えられます。機密情報を扱う場合は、この設定や有料版・法人向けプランも含めて検討します（初級編でご案内）。

👤 1人1アカウントで運用

1つのアカウントを複数人で共有するのは、利用規約・プライバシー・アカウント凍結のリスクの面で非推奨。今後の社内展開を考えても、1人1アカウントが安全です。

🆓 まずは無料版で「慣れる」

今期はAI導入の準備期間。まずは無料版で使い方に慣れ、本格的に業務で使う段階で、機能やデータの扱いに応じて有料版・法人プランへの切り替えを検討する、という進め方が無理がありません。

🧩 「特定の1人に依存しない」設計

池田様のご希望どおり、社内のみんなが運用できることを前提に設計します。手順を分かりやすく残す・共有する仕組みを整えることで、引き継ぎや属人化の不安にも備えられます。

Prompt Basics
プロンプトの「5つの要素」
プロンプト＝AIへの指示文。具体的かどうかで回答の精度が大きく変わります。難しい作業ほど、次の5要素を入れると精度が上がります。
①
役割
Role
誰として答えてほしいか。例：「あなたは経験豊富な経理担当です」
②
依頼
Task
何をしてほしいか。明確に。例：「この明細を科目ごとに整理して」
③
目的
Purpose
なぜ依頼したか。ゴールが伝わると回答が的確に。
④
回答方法
Format
どう答えてほしいか。例：「表で」「箇条書きで」
⑤
条件
Rule
守ってほしいルール。例：「専門用語は使わずに」
📝 5要素は必須ではありません。 明日の天気を聞くだけなら②だけでもOK。難しい作業ほど5要素を入れる──こう考えると、プロンプト作成のハードルが上がりすぎません。新人さんに具体的に指示するイメージが近いです。

🎓 初級編 — 2026年9月18日（金）9:30〜13:00｜全13テーマ

✅ 初級編のテーマは「機能理解」。 「機能 → 考え方 → 活用方法」の順で進む研修の第1段階として、有料版ChatGPTで“何ができるか”を体験しました。次回の中級編（10/8）で、これを経理・設計など御社の実務へ応用していきます。
01AIと生成AIの基本概念完了
＋
  • AI＝人間の頭脳のように考えたり学んだりできるコンピューターの総称用語。
  • 生成AI＝指示によって文章・画像・動画などの新しいコンテンツを生み出す技術の分野（AIという大きなくくりの中の一分野）。
  • 物の破損を見分けるだけの「識別AI」など、何かを生み出さないAIもある。ChatGPT・Gemini・Copilotなどは生成AIの仲間で、今回学ぶのがChatGPT。
  • イメージ：「スポーツ」の中に野球・サッカーがあるように、「AI」の中に「生成AI」がある。
02AIが力を発揮する場所／経理での注意点完了
＋
  • 生成AIが本領発揮するのは「考えることが必要な業務」＝答えが一つに決まっていない業務。情報収集・アイデア出し・文章作成・戦略立て・財務分析など。
  • 単純なデータ入力・転記はあまり向かない（頭を使わない作業のため）。
  • 経理など「間違えてはいけない数字」を扱う業務は慎重に。 AIは100%の精度を保証できないため、仕分けの下ごしらえはAIに任せ、最終確認は必ず人が行うのが安全。
  • 仕事だけでなく、旅行計画・ファッションなどプライベートの“考える場面”でも活用できる。
03基本操作・チャット管理完了
＋
  • メイン画面（会話するところ）とサイドバー画面（履歴・機能）の見方。
  • 実演：建設業の営業メールを3パターン生成 →「もっとカジュアルに」等の修正指示で最適化。一発で完璧を狙わず、何度か往復して仕上げるのが基本。
  • 同じ指示でも毎回まったく同じ回答にはならない。会話を続けるほど前の内容を踏まえて精度が上がる。
  • 送信済みプロンプトの修正（文字にカーソルを合わせると出る鉛筆マーク）、Shift+Enterで改行。
  • 回答に時間がかかる間も、別タブでもう1つ開いて並行作業できる。
04画像生成完了
＋
  • 「以下の情報で画像生成してください」＋テーマ・情報・色・比率などを指定。実演：建設業の求人ポスター。
  • 主要AIの中でChatGPTは画像生成が得意。リアルな写真風・広告画像も作れる。
  • 修正指示が非常に得意：「他の要素は変えず、中央のグラスだけ大きく」「背景をベージュに」など、部分だけ変更できる。
  • 建設向け：木目を生かした和モダンのリビング×造り付け収納家具の完成イメージ。細かく指示するほど再現性が上がる。
  • 画像サイズも指定可（正方形＝1:1、縦長＝9:16 など）。著作権・肖像権に配慮し、キャラクターに似せて作るのはNG。
05画像・図面の認識完了
＋
  • 画像を添付して読み取り。実演：料理写真 → 材料・作り方を推定。
  • 活用例：Excelエラーのスクリーンショット → 解決方法、ホワイトボード写真 → 議事録、料理写真 → カロリー計算、パーソナルカラー診断など。
  • 建設向け：内装のbefore写真を読ませて完成イメージを生成。図面（画像・PDF）を読み取って要点を箇条書き → 間取りを理解させた上で完成イメージを作成。
  • コツは「まず現状を理解させる → その上で作らせる」。この順番だと精度が上がる。
06ファイルの読み取り・データ分析完了
＋
  • ファイルを添付して分析。実演：家電量販店の年間売上データ → 分析レポート＋グラフを生成。
  • 資料の読み取り精度は90%前後。決算書の財務分析・売上予測、契約書のリーガルチェック（一次チェック）、サービス資料の要約、比較表づくりなどに活用。
  • 決算資料など機密情報は、そのまま渡さずマスキング／ダミーに置き換えるのが基本。
07情報収集完了
＋
  • Google検索の代わりに使える。実演：建設業界のAI活用ニュースを10個リストアップ →「1つ目を深掘りして初心者向けに解説」で理解を深める。
  • 会社HPのURLを読ませて企業分析（お打ち合わせ前の下調べ・競合分析）。引用元のリンクも表示される。
  • 注意：ログインが必要なサイト（SNS・会員制ニュース・クラウドツールなど）は読み取れない。
  • 「メール対応・情報収集・資料作成」は、多くの企業でAI効率化の効果が出やすい業務トップ3。
08資料作成（プレゼン・Word・Excel）完了
＋
  • 「以下の情報でプレゼン資料を作成」＋テーマ・枚数・デザインを指定。実演：経費計上の手順マニュアルを作成。
  • PowerPoint（.pptx）・Word・ExcelとしてダウンロードOK。細かく指示するほど高品質に。
  • 「2〜3時間かけて資料を作る」時代から、たたき台を数分〜数十分で作り、仕上げに集中する使い方へ。
09「チャット」と「ワーク」の使い分け完了
＋
  • チャット＝単発でスピーディ。利用回数の上限は特になし。簡単な相談・メール・ブログ・報告資料向き。
  • ワーク＝情報収集・分析・自己チェック・修正まで複数ステップを踏むため高品質。ただし時間がかかり、利用制限（クレジット）がある。プレゼン・Excel・市場調査・複雑な戦略づくり向き。
  • ワークは複数画像の生成も可。利用状況は「設定 → 利用状況」の5時間上限（デフォルト100%）で確認でき、使うほど減る。5時間で回復、追加購入も可。
10Excelデータの生成完了
＋
  • 「年間売上管理シートを作成」＋関数・条件付き書式・グラフ・使い方シートまで指定。実演：数式（SUMIF・IFERROR）や条件付き書式（基準超は緑・下回れば赤）入りのシートを約11分で生成。
  • 案件進捗・タスク管理・売上管理など、エクセルスキルがなくても実用的なシートを作れる。
11経理の仕分けを効率化する【最優先・応用】完了
＋
  • 池田様の最優先テーマ。カギは「仕分けのルールを言語化してAIに教えること」。頭の中にあるルール（同じメーカーでも現場・品目ごとに科目を分ける等）を文章にするのが一番の肝。
  • 進め方：①仕分け前データ（カード明細のCSVなど）②仕分け後のテンプレート③仕分けルールの3点をAIに渡す → 仕分け後のデータ／CSVを出力 → 経理ソフトにインポート。
  • カード明細は口座・カードからCSVで書き出せる。プライベート分は「計上しない」ルールをAIに教えておく。
  • 実演：経費整理用フォルダ（ルール・テンプレート・入力データ）で、カード明細の先頭10件を仕分け・集計。
  • ※ 次回の中級編で、池田様の実際のデータを使って実践予定（すぐの宿題ではありません）。金額の最終確認は必ず人が行います。
12モデル選択・思考量の調整完了
＋
  • メッセージボックス右のバーで「インスタント／中程度／高い／極高」＝考える量を切り替えられる。
  • 右にするほど深く考えて精度が上がるが、時間がかかる（ワークではクレジット消費も増える）。
  • 目安：急ぎ・簡単は「インスタント」、難しい戦略や調査は右寄り。チャットは基本「中程度以上」がおすすめ。
13プロジェクト機能（履歴管理＋情報源）完了
＋
  • チャット履歴をフォルダのように整理できる機能。「1チャット＝1お客様」「1チャット＝1業務（3月度の経費計上…）」で管理すると探しやすい。
  • 「情報源（コンテキスト提供）」に資料を入れておくと、そのプロジェクト内の会話で常に参照してくれる。経費計上のルールやマニュアルを入れておくと便利。
  • ※ 宿題ではありませんが、次回までにプロジェクトをいくつか作ってみるのがおすすめです。

  • 公式LINEグループ：研修外でも質問できる窓口。画像がうまく読み取れない等、つまずいたら送ってOK。
  • 次回（中級編 10/8）までのお願い： ①プロジェクトをいくつか作ってみる ②画像生成・プレゼン資料作成を試す ③経理の仕分けで使っているデータを用意（実演に使用）。
